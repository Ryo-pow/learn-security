# 情報まもりランド ― 情報漏えい体験ゲーム

架空の会員サイトやトランプを題材に、来場者が**遊びながら**「情報が漏れるしくみ」と「守り方」を学べる体験ゲームです。
2つのゲームと、むずかしい言葉をその場で引ける**用語集**が入っています。

- 通信はすべて**サーバーを動かすPCの中（同じWi-Fi内 / localhost）だけ**を通り、クラウドや外部インターネットには一切出ません。
- 会員データは**すべて自動生成の架空データ**です（メールは `@example.com`、電話は `090-0000-xxxx` など）。入力したニックネーム・パスワードもこのPCのメモリに一時保存されるだけで、ファイルにも外部にも残りません。
- 専門用語は、画面の**青い下線つきの言葉をタップ**するとその場で解説が出ます（ホームの「📖 用語集」で一覧も読めます）。
- どの画面にも「👇 〜を押してね」の案内が出るので、来場者は案内どおりに進めば遊べます。

---

## 2つのゲーム

### ゲーム① 情報まもりクエスト（1人で遊べる）
最初に架空サイトへ“自分の偽アカウント”を登録し、4つの事件を解きながら学びます。

各事件は次の順に進みます。

1. **予想する** ― 「どうなると思う？」に2択で答える（答えが先に分からないよう、伝えたいことはまだ出さない）
2. **やってみる** ― 使う人になって、実際に操作して確かめる
3. **まとめ** ― 「この事件で伝えたいこと」のあと、タブで切り替えて読む
   - 👤 **使う人の目線**：何が起きたか／自分にできること（パスワードを使い回さない、二段階認証 など）
   - 🛠 **作る人の目線**：なぜ起きたか／正しい作り方（CWE番号つき）

| 事件 | やること | 伝えたいこと | 脆弱性 |
|---|---|---|---|
| ① 会員番号の書き換え | マイページの会員番号を他人の番号に変えて開く。最後に全会員を一気に取り出す | 番号だけで「誰の情報か」を決めると、他人の情報も全員分も（自分の分も）漏れる | IDOR / CWE-639・862 |
| ② 画面の裏側のぞき | 名前とポイントしか出ていないマイページが、裏で受け取っている情報を見る | 画面に出ていなくても情報は届いている。入力したパスワードがそのまま返ってくるサイトは、パスワードをそのまま保存している | CWE-200・256・602 |
| ③ 暗号のふり見破り | 「暗号化済み🔒」の会員メモを解読する | 「暗号化」に見えても base64 はただの変換。表示や🔒だけで安全とは限らない | CWE-326 |
| ④ 値段の書き換え | 購入画面の値段を書き換えて購入する | 値段などの大事な値を画面任せにすると、書き換えられてしまう | CWE-602 |

事件①と④には「対策を有効にする」スイッチがあり、正しく作ったサイトでは同じ操作が通らないことも確かめられます。
最後にまもりポイント（最大600）と称号が出ます。

### ゲーム② のぞき見チャレンジ（2台をローカルでつないで対戦）
片方がトランプのカードを選んで出題し、もう片方が当てるゲームです。…が、**出したカードは相手の端末にこっそり届いて**います。画面では裏向きでも、中身は届いているのです。

**“のぞき見”できるのは、PCで開発者ツールのコマンド `peek()` を実行した人だけ**です。画面に「のぞき見ボタン」はありません（スマホの人や普通の来場者はのぞけません）。これが「気づかないうちに、技術のある人には見られている」という体験そのものです。

#### 対戦の組み合わせ：パソコン 対 もう1台のデバイス

| | 用意するもの | 役割 |
|---|---|---|
| **パソコン**（出展者側） | **開発者ツール（開発者モード）を開いて、Console が使える**ブラウザ（PC版の Chrome / Edge など） | カードを当てる側。`peek()` でのぞき見する |
| **もう1台のデバイス**（来場者側） | スマホ・タブレット・別のPCなど（ブラウザが使えれば何でもOK） | カードを選んで出題する側 |

※ PCの2つのブラウザ（タブ）同士でも試せます。

#### 進め方（のぞき見 → 種明かし）

1. **2台をつなぐ**：両方のブラウザで同じ `http://...:8788` を開き、ゲーム②を選んで、**同じ「あいことば」**を入れて「対戦にはいる」。
2. **相手が出題する**：もう1台のデバイスで、出したいカード（マークと数字）を選んで「このカードで出題する」。パソコンの画面では、そのカードは**裏向き**で表示されます。
3. **パソコンで開発者ツールを開く**：Windows は `F12`、Mac の Chrome / Edge は `⌥ option ＋ ⌘ command ＋ J`。開いたら「**Console**」タブを選ぶ。
4. **`peek()` を実行する**：Console に `peek()` と入力して Enter。相手が選んだカード（例：`♥7`）が赤い大きな文字で表示されます。
5. **相手のカードを当てる**：パソコンの画面で、`peek()` で分かったマークと数字を選んで「これだ！回答する」。
6. **種明かしを見せる**：`peek()` を実行した時点で、相手のデバイスの画面には「**💥 のぞかれました！**」と表示され、
   - 出したカードは、画面では裏向きでも、勝敗判定のために**相手の端末にこっそり送られていた**こと
   - base64 で見た目を変えていても、ただの変換なので誰でも元に戻せること
   - 正しい作り方（答えはサーバー側に隠し、回答し終わってから送る）

   が説明されます。「画面に出ていない＝安全ではない」ことを、相手の画面を見せながら伝えてください。

   > ⚠ 手順5で回答すると、相手の画面は「相手は当てました 🎯」の結果画面に切り替わり、この説明は消えます。**種明かしの説明は、回答する前（手順4のあと）に相手の画面で見せておく**のがおすすめです。

## 必要なもの

- サーバーを動かす**PC1台**（Mac / Windows / Linux）に **Node.js**（`node -v` でバージョンが出ればOK。無ければ https://nodejs.org/ ）
  - Node.js の標準機能だけで動くので、`npm install` などの追加インストールは不要です。
- ゲーム①は端末1台でOK。ゲーム②は**このプログラムを起動しているPCともう一つのデバイス（スマホでもパソコンでも可）**（または同じPCの2つのブラウザ/タブ）

## 起動のしかた

1. このフォルダ（`server.js` がある場所）をターミナルで開く
   - `server/` フォルダと `client/` フォルダ、`client.html` も同じ場所に必要です
2. 次のコマンドを実行

   ```
   USERS=3000 node server.js
   ```

3. 表示されるURL（`http://localhost:8788` や `http://192.168.x.x:8788`）をブラウザで開く(`http://192.168.x.x:8788`で開いた方が後のゲーム2でQRコードを出してスマホと連携しやすいのでおすすめです)
4. ホームでゲームを選ぶ

**会員の人数を変更したいときは、`USERS=` の数を変更してください。**（50〜5000人。例：`USERS=1000 node server.js`。`USERS=` を付けずに `node server.js` だけで起動すると1000人になります）

ポート変更：`PORT=9000 node server.js`。終了：`Ctrl + C`。

> ⚠ 来場者の偽アカウントはメモリにだけ保存しています。**サーバーを再起動すると消える**ので、遊んでいる途中の人がいるときは再起動しないでください（消えた場合は画面に「登録し直してください」と出ます）。
> 画面のファイル（`client.html`）はサーバー起動時に読み込むので、編集したら再起動して反映させます。

## この展示が伝える教訓

どのゲームも共通するのは「**利用者の端末から来たものを、信じすぎた**」こと。
端末に届いたデータは画面に出していなくても読まれ、端末から来た値（番号・値段）は書き換えられます。
**守りたいものは、そもそも端末に渡さないか、サーバー側で守る。**

そして使う人の側でも、**パスワードを使い回さない・二段階認証を使う・必要以上の情報を登録しない**ことで、被害を小さくできます。

### うまくつながらないとき（ゲーム②）

- 2台（またはPCの2タブ）が同じサーバーのURLを開き、**同じあいことば**になっているか確認してください。
- PCのファイアウォールが `node` の通信をブロックしている場合、許可してください。
- 片方が「相手を待っています…」のままなら、もう一方のあいことばの打ち間違いが多いです。
