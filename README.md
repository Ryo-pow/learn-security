# 情報まもりランド ― 情報漏えい体験ゲーム（ローカル版）

架空の会員サイトやトランプを題材に、来場者が**遊びながら**「情報が漏れるしくみ」と「守り方」を学べる体験ゲームです。
2つのゲームと、むずかしい言葉をその場で引ける**用語集**が入っています。

- 通信はすべて**サーバーを動かすPCの中（同じWi-Fi内 / localhost）だけ**を通り、クラウドや外部インターネットには一切出ません。
- 会員データは**すべて自動生成の架空データ**。入力したニックネーム・パスワードもこのPCの中だけに一時保存され、外部に出ません。
- 専門用語は、画面の**青い下線つきの言葉をタップ**するとその場で解説が出ます（ホームの「📖 用語集」で一覧も読めます）。

---

## 2つのゲーム

### ゲーム① 情報まもりクエスト（1人で遊べる）
「ホワイトハッカー見習い」として、4つの事件を解きながら学びます。各事件は **「予想 → 自分で実演 → 答え合わせ・解説」** の流れ。

| 事件 | 体験すること | 脆弱性 |
|---|---|---|
| ① 他人の番号 | 番号を変えると他人の情報が見え、やがて**全員分**（自分も含む）が一気に漏れる | IDOR / CWE-639・862 |
| ② 画面の裏側 | 名前しか表示してない画面の“生データ”に、登録したパスワードまで届いている | CWE-200・602 |
| ③ 暗号のふり | 「暗号化済み🔒」が実は base64 で、ワンタップ解読 | CWE-326 |
| ④ 値段の改ざん | 購入額を1円に書き換えると、サーバーがそのまま請求 | CWE-602 |

最初に作った“自分の偽アカウント”が、事件①の漏えい一覧の先頭に強調表示で流れてきます。まもりポイント・称号つき。

### ゲーム② のぞき見チャレンジ（2台をローカルでつないで対戦）
最初のトランプ当てゲームの体験版です。片方がカードを引き、もう片方が当てる…はずが、**引いたカードは相手の端末にこっそり届いて**います。画面には裏向きでも、中身は届いているのです。

**“のぞき見”できるのは、PCで開発者ツールのコマンド `peek()` を実行した人だけ**です。画面に「のぞき見ボタン」はありません（スマホの人や普通の来場者はのぞけません）。PCの人が `peek()` を実行すると相手のカードが見え、のぞかれた側の画面には「💥 のぞかれました！」と出ます。これが「気づかないうちに、技術のある人には見られている」という体験そのものです。

**つなぎ方：** 2台のブラウザで同じ `http://...:8788` を開き、**同じ「あいことば」**を入れるとつながります。のぞき見の実演には片方がPCである必要があるので、出展では「出展者のPC（localhost）＋来場者のスマホ」や「PCの2つのタブ」がおすすめです。

**のぞき見の手順（PC側）：** 相手がカードを引いたあと、`F12`（Macは `⌥⌘I`）→「Console」タブ → `peek()` と入力して Enter。

## 必要なもの

- サーバーを動かす**PC1台**（Mac / Windows / Linux）に **Node.js**（`node -v` でバージョンが出ればOK。無ければ https://nodejs.org/ ）
- ゲーム①は端末1台でOK。ゲーム②は**2台**（または同じPCの2つのブラウザ/タブ）

## 起動のしかた

1. `server.js` と `client.html` がある場所をターミナルで開く
2. `node server.js` を実行
3. 表示されるURL（`http://localhost:8788` や `http://192.168.x.x:8788`）をブラウザで開く
4. ホームでゲームを選ぶ

人数を増やして迫力を出すとき：`USERS=3000 node server.js`（50〜5000人）。ポート変更：`PORT=9000 node server.js`。終了：`Ctrl + C`。

## 「攻撃」をもっと見せたいとき（出展者向け・任意）

来場者はボタンだけで体験できますが、「このボタンは、技術がある人なら誰でもできることの代行」と示すと説得力が増します。PCのブラウザで `F12`（Macは `⌥⌘I`）→「Console」タブで：
- ゲーム①：`peek(25)` で25番の会員、`leakAll()` で全員取得
- ゲーム②：対戦中に `peek()` で相手のカードを表示

いずれも**自分の端末に届いているデータを読んでいるだけ**で、相手や来場者の画面には出ません。

## この展示が伝える、たった1つの教訓

どのゲームも共通するのは「**利用者の端末から来たものを、信じすぎた**」こと。
端末に届いたデータは画面に出していなくても読まれ、端末から来た値（番号・値段）は書き換えられます。
**守りたいものは、そもそも端末に渡さないか、サーバー側で守る。**

## ⚠ お願い

これは**わざと弱く作った練習用の箱庭**です。学んだ操作を現実の他人のサイトやシステムに試すと不正アクセスにあたります。あくまで「守る側の視点」を持ち帰るために使ってください。

### うまくつながらないとき（ゲーム②）

- 2台（またはPCの2タブ）が同じサーバーのURLを開き、**同じあいことば**になっているか確認してください。
- PCのファイアウォールが `node` の通信をブロックしている場合、許可してください。
- 片方が「相手を待っています…」のままなら、もう一方のあいことばの打ち間違いが多いです。
